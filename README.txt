IJ7 Game website package
=========================

Upload these files to the root of your website:
- index.html
- sitemap.xml
- robots.txt
- images/

Important:
1. Keep the images folder and filenames unchanged.
2. After publishing, open https://ij7geme.com/ and check all 4 images.
3. In Google Search Console, add https://ij7geme.com/ and submit:
   https://ij7geme.com/sitemap.xml
4. Request indexing for:
   https://ij7geme.com/
5. Google ranking is not guaranteed by HTML/SEO alone; content quality, indexing, links, site reputation and competition also matter.
